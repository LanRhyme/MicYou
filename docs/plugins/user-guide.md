# 用户指南

面向 MicYou 用户的插件使用说明：安装、卸载、GUI 管理、配置与跨端同步

## 安装插件

### 从插件市场安装（推荐）

设置-插件 → 点「插件市场」按钮 → 浏览列表 → 点「安装」→ 核对能力清单后确认

- 市场读取 MicYou-Plugins 仓库的 index.json（GitHub Pages 部署，根除 CDN 缓存）
- 安装前先拉取远程 manifest 展示能力供确认，确认后才下载 zip 安装
- 已安装的插件在市场列表显示「已安装」


插件有两种分发形态：**插件目录**（含 `plugin.json` + 入口产物）与 **插件压缩包**（.zip，解压后即插件目录）

1. 打开 GUI，进入 设置-插件 页面
2. 点击「打开插件目录」获取宿主插件目录路径：
   - Linux / macOS：`~/.config/micyou/plugins/`
   - Windows：`%APPDATA%\micyou\plugins\`
3. 把插件文件夹（或解压后的 .zip 内容）放入该目录，每个插件一个子目录
4. 回到插件面板点击「刷新」

插件出现在列表中即安装成功；若加载失败会显示具体错误原因（如入口文件缺失、清单校验失败、Host API 版本不匹配）

## 卸载插件

- 插件面板中点击垃圾桶图标，确认后插件被禁用、从注册表移除并删除目录
- 也可手动删除插件目录（重启或刷新后生效）

## 在 GUI 中管理插件

| 操作 | 位置 |
| --- | --- |
| 启用 / 禁用 | 插件卡片右侧开关（启用即加载运行时并接入 DSP 链） |
| 卸载 | 垃圾桶图标 |
| 查看日志 | 终端图标（每个插件独立的环形日志缓冲，最多 500 行） |
| 编辑配置 | 拼图图标（JSON 编辑器，保存后写入 `plugin-state.json`） |
| 跨端状态 | 面板右上角徽标（设备已连接 / 无设备） |

## 插件专属设置页

- 声明 `ui.panels` 的插件会在设置对话框侧边栏（「插件」之后）显示专属页面入口
- 页面是插件自带的 HTML，在沙箱 iframe 中渲染，可读取配置、触发动作、播放音效
- 示例：soundpad 的「控制台」页（查看音效、点击播放）

## 全局快捷键

- 插件可注册系统级快捷键（如 soundpad 的 Ctrl+Shift+S 播放第一个音效）
- 快捷键在任何应用前台都生效，触发后插件收到 `hotkey` 消息

## 音效板（soundpad 插件）

- 启用 soundpad 类插件后，插件页会出现按钮网格（按钮来自插件配置的 `sounds` 数组）
- 首次启用自动生成示例音效，直接点击按钮即可播放
- 想用自己的音效：编辑插件配置的 `sounds` 数组，`file` 填 WAV 路径（相对路径指向插件目录）

## 安装与权限确认

- 导入 zip 前弹出**权限预览**：名称/作者/许可/请求的能力清单
- 确认来源可信后安装；插件仅能使用其声明的能力（越权调用被宿主拒绝）

## 更新插件

- 插件声明 `updateUrl` 时可在插件页点「检查更新」
- 有新版显示当前 → 最新版本，点「更新」下载替换并自动恢复启用状态

## 配置插件参数

1. 打开插件面板，点击插件卡片的配置图标
2. 在 JSON 编辑器中写入配置，例如：

```json
{ "gain": 2.0, "threshold": -40.0 }
```

1. 点击「保存」

配置写入宿主的 `plugin-state.json`（与插件 id 关联），插件通过 Host API `get_config` 读取；修改配置后通常需要禁用再启用插件以使其重新读取（取决于插件实现，多数 DSP 插件在 init 时读取）

## 跨端插件同步

当手机（安卓客户端）与电脑建立连接后，两端的插件系统自动可通信：

- 手机插件与电脑插件通过同一消息协议（`PluginMessage`）互发消息
- 电脑插件可用 `message.send` 定向到 `remote` 目标（如手机上的传感器插件）
- 手机插件采集的数据（传感器、电池等）可实时推给电脑插件处理，处理后结果回传
- 跨端状态在插件面板右上角显示（设备已连接）

> 说明：安卓端插件运行时按规划将在后续版本提供，协议与总线已就绪，当前安卓客户端仅提供基础控制消息，插件消息通道对安卓端属于预留能力

## 常见问题

### 插件显示加载失败

检查：入口文件名与 manifest `entry` 是否一致、平台是否在 `platforms` 中、`apiVersion` 是否为 1、Native 插件是否为本平台构建产物

### 启用插件后声音异常 / 静音

立即禁用该插件；实时 DSP 插件质量问题（爆音、缓冲）通常源于插件未遵循实时安全规范，详见[开发指南](development-guide.md#实时-dsp-插件规范)

### 插件配置不生效

确认插件已启用并重新加载（禁用 → 启用），或查看插件日志确认 `get_config` 是否读取到值
